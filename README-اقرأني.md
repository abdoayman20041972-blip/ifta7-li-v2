# تطبيق "افتح لي" (النسخة 3)

تكتب اسم التطبيق (أو تقوله بميكروفون الكيبورد) فيفتحه. مثال: "افتحلي الواتس" أو "شغللي يوتوب" أو "open camera".

## الجديد في النسخة 3
- **الصوت داخل التطبيق:** زر ميكروفون يستخدم خدمة التعرف على الكلام من Google (لغة ar-EG)، ويحتاج إنترنت.
- **دائرة عائمة 🎤** فوق التطبيقات: اضغطها، قل اسم التطبيق، فيُفتح. تقدر تسحبها لأي مكان.
- **الأذونات المطلوبة:** الميكروفون، والعرض فوق التطبيقات الأخرى، والإشعارات (الدائرة تعمل كخدمة أمامية بإشعار فيه زر "إيقاف").
- أُضيف بروفايل `production` في `eas.json` (يطلع APK أيضًا) لتجنّب خطأ "Missing build profile".

## الجديد في النسخة 2
- **بيقرأ التطبيقات المثبتة فعلاً على جوالك** (مش قائمة محفوظة). أي تطبيق تثبّته بعد كده يظهر بعد ضغطة على "تحديث قائمة التطبيقات".
- **تضيف أوامر فتح جديدة بنفسك** من تبويب "أوامري": تكتب الجملة (مثل "مزرعتي")، تختار التطبيق، تحفظ. الأوامر بتتحفظ على الجوال وبتفضل بعد قفل التطبيق.
- لو قلت أمر ما فهمهوش، بيظهر زر **"علّمني الأمر ده"** يوديك على نفس الشاشة والجملة مكتوبة.
- الأمر اللي إنت بتضيفه له **الأولوية** على الفهم التلقائي.
- من غير إذن "قراءة كل التطبيقات" الحساس. بيستخدم بس إذن رؤية التطبيقات اللي ليها أيقونة تشغيل.

## إزاي بيفهم الأوامر
1. أوامرك المحفوظة أولاً.
2. بعدين اسم التطبيق زي ما هو مكتوب على جوالك (مثلاً `Camera` أو `Calculator`)، وكمان الأسماء الدارجة للتطبيقات المعروفة (واتساب = الواتس، فيسبوك = الفيس...) الموجودة في `apps.js`.
3. بيتحمل أخطاء إملائية بسيطة.

## حدود لازم تعرفها
- ده **مش** ذكاء اصطناعي متدرّب. هو قواعد لتنظيف الجملة ومقارنتها بأسماء التطبيقات، وده مناسب جدًا لهدف واحد زي ده.
- **الأسماء العربية للتطبيقات الأجنبية**: لو تطبيق اسمه على الجوال بالإنجليزي (مثل `Vodafone Ana`) وإنت بتقول "فودافون"، التطبيق مش هيعرف يربطهم لوحده. حل المشكلة دي بأمر مخصص مرة واحدة ("فودافون" ← Vodafone Ana). الأسماء الدارجة للتطبيقات المشهورة (واتساب، يوتيوب...) مجهزة سلفاً.
- **لو أمرك ينطبق على أكتر من تطبيق** (مثل "جوجل" وعندك Google Maps وGoogle Photos) هيسألك تقصد أنهي واحد بدل ما يخمّن.
- الصوت: بيعتمد على ميكروفون لوحة المفاتيح، مش ميكروفون داخل التطبيق.
- **الصوت والدائرة العائمة** يعتمدان على تطبيق Google وعلى الإنترنت، وبعض الجوالات توقف الخدمات الخلفية (استثنِ التطبيق من توفير البطارية لو الدائرة اختفت).
- **ما يشتغلش على Expo Go.** فيه جزء أندرويد أصلي، فلازم تثبّت ملف الـ APK الكامل.
- بيفتح التطبيقات اللي ليها أيقونة تشغيل بس (مش خدمات النظام الخفية).
- ما اتجربش على جهاز حقيقي قبل ما أسلمه لك (مفيش أدوات بناء أندرويد في بيئتي). منطق الفهم اتختبر بـ 42 حالة، وكود الواجهة اتجمّع بنجاح. أول تشغيل على جوالك هو الاختبار الفعلي، قولي لو ظهر أي خطأ.

## إزاي تطلع ملف APK (نفس طريقة "نور اليوم")
1. ارفع كل ملفات المجلد على مستودع GitHub (اسمه مثلًا `ifta7-li`). **تأكد إن مجلد `modules` اترفع** (فيه جزء قراءة التطبيقات)، وما ترفعش `node_modules`.
2. من موقع Expo اربط المستودع بمشروع.
3. شغّل Build لأندرويد بالبروفايل `preview` أو `production` (جاهزين في `eas.json` وبيطلع APK).
4. نزّل الملف على جوالك وثبّته. لو ظهر تحذير "مصدر غير معروف" اسمح بالتثبيت.

ولو عندك الأداة على كمبيوتر:
```
npm install
npx eas-cli build --platform android --profile preview
```

## الملفات
- `App.js`: الشاشة (تبويب التطبيقات + تبويب أوامري).
- `matcher.js`: منطق فهم الجملة.
- `appList.js`: دمج التطبيقات المثبتة مع الأسماء الدارجة.
- `apps.js`: الأسماء الدارجة للتطبيقات المشهورة (تقدر تضيف عليها).
- `modules/installed-apps/`: الجزء الأصلي بتاع أندرويد (قراءة التطبيقات وفتحها، `SpeechEngine.kt` للصوت، `BubbleService.kt` للدائرة العائمة).
- `test-matcher.js`: اختبارات الفهم. تشغيلها: `node test-matcher.js`.
